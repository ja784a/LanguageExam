# LanguageExam
本アプリケーションは就職活動のポートフォリオとして制作した外国語試験予約サイト（ダミー）です。<br>
受験者が試験を予約したり、管理者がサイトの設定を行うことを想定して作成しました。<br>
# 本アプリケーションを実行いただく前に
・プロジェクトに同梱のschema.sql(LanguageExam/src/main/resources/schema.sql)、およびdata.sql(LanguageExam/src/main/resources/data.sql)を実行して必要なデータを追加してください。<br>
・本アプリケーションはdata.sqlのマスターデータの組み合わせで動作することを想定しています。<br>
・本アプリケーションはユーザー向け機能と管理者向け機能に分かれています。data.sqlを実行した後、ログイン画面でユーザー向け、または管理者向けのメールアドレス、パスワードを入力してください。<br>

# 主な機能
【ユーザー向け機能】<br>
・試験案内(ログイン不要）・・・試験の一覧を表示する<br>
・試験詳細（ログイン不要）・・・試験の会場、試験日、受験料を表示する<br>
・お知らせ詳細（ログイン不要）・・・お知らせの本文を表示する<br>
・試験予約（要ログイン）<br>
・試験予定（要ログイン）・・・予約した試験の一覧を表示する<br>
・試験予約変更（要ログイン）・・・試験の予約内容を変更する<br>
・キャンセル（要ログイン）・・・予約した試験をキャンセルする<br>
・アカウント管理（要ログイン）・・・アカウント情報を管理する<br>
【管理者向け機能】<br>
・試験管理（要管理者ログイン）・・・試験の追加、試験日変更、中止の設定を行う<br>
・受験料管理（要管理者ログイン）<br>
・お知らせ管理（要管理者ログイン）<br>

# 工夫した点
・不正な入力などを想定した独自のバリデーション機能を実装し、アプリケーションの安全性を高めました。 <br>
・データ表示の順序付けやページネーションのページリンク件数の指定、ボタンの色分けなど、ユーザーが直感的に操作できる画面表示を実現しました。 <br>
・文字と背景色の組み合わせを調整し、弱視の方でも文字が読みやすくなるように工夫しました。 <br>
# 苦労した点
・要件定義では、アプリケーションの目的、システムの要件と機能の定義を分けて考えることに時間がかかりました。 <br>
・実現したい機能をそのまま目的として書いてしまったり、技術的な実装内容を要件として扱ってしまうことがあり、時間をかけて分類を整理しました。 
・画面設計では、設計書として人に理解してもらうことを意識するのに苦労しました。 <br>
・自分で考えた作品なので、自分の中で自明となっている箇所の説明を省いてしまったり、見た目を意識するあまり設計書としての側面をおろそかにしてしまうことがありました。 <br>
・フォーマットの全面的な見直しや部品番号の付番など、試行錯誤してアプリケーションの前提条件を知らない人であっても円滑に理解できる設計書の作り方を学びました。 <br>
・実装面では、データベースの複数のテーブルを階層状に取得することに苦労しました。 <br>
・まず自分でやり方を調べたりAIを活用したものの理解できず、就労訓練の講師からの助言を受けて理解することができました。 <br>
・自分で考え込むことで時間を浪費してしまったり、質問の際にうまく言葉をまとめられなかったことが反省点として残りました。 <br>
