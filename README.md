# LanguageExam
本アプリケーションを実行いただく前に以下の初期設定を行ってください。<br>
・schema.sqlの各コードを用いてデータベースを作成してください。<br>
・data.sqlの各コードを利用して必要なデータを追加してください。<br>
・本アプリケーションでは管理者権限専用機能があります。管理者アカウントの作成の際は、まずアカウント登録ページでアカウントを作成の上、data.sqlのコードを用いてアカウント権限を変更してください。その際、IDを指定してください。<br>
・サンプルデータを追加いただくと、英語試験の予約処理が可能となります。<br>
・本アプリケーションはdata.sqlに用意したマスターデータの組み合わせでの動作を想定しています。<br>
schema.sql・・・LanguageExam/src/main/resources/schema.sql<br>
data.sql・・・LanguageExam/src/main/resources/data.sql
