# LanguageExam
本アプリケーションは外国語試験予約サイト（ダミー）です。<br>
受験者が試験を予約したり、管理者がサイトの設定を行うことを想定して作成しました。<br>
# 主な機能
【ユーザー向け機能】<br>
・試験案内(ログイン不要）・・・試験の一覧を表示する<br>
・試験詳細（ログイン不要）・・・試験の会場、試験日、受験料を表示する<br>
・お知らせ詳細（ログイン不要）・・・お知らせの本文を表示する<br>
・試験予約(要ログイン）<br>
・試験予定（要ログイン）・・・予約した試験の一覧を表示する<br>
・試験予約変更（要ログイン）・・・試験の予約内容を変更する<br>
・キャンセル（要ログイン）・・・予約した試験をキャンセルする<br>
・アカウント管理(要ログイン）・・・アカウント情報を管理する<br>
【管理者向け機能】<br>
・試験管理（要管理者ログイン）・・・試験の追加、試験日変更、中止の設定を行う<br>
・受験料管理（要管理者ログイン）<br>
・お知らせ管理（要管理者ログイン）<br>
